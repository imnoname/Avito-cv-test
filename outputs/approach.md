# Краткое описание подхода

Для обучения использовался открытый датасет TextOCR с размеченными боксами слов. Из него отбирались достаточно крупные почти горизонтальные кропы. Для каждого кропа автоматически создавалась пара примеров: исходное изображение и его поворот на 180°. Компактная сверточная сеть обучалась отличать эти две ориентации; модель обучена с нуля и содержит около 97,7 тыс. параметров.

Качество и калибровка вероятностей проверялись на кропах из отдельной официальной части TextOCR, также превращённых в пары 0°/180°. На инференсе каждый тестовый бокс оценивается в исходном и повёрнутом виде, а разность оценок преобразуется в `p_180`. На синтетической валидации Brier Score составил 0,0762. Это значение не является оценкой на тесте соревнования: истинные метки тестовых изображений неизвестны.

Решение реализовано на PyTorch, NumPy и Pillow; предобученные модели и внешние API не используются. Для воспроизведения зафиксирован seed 42. Подробные команды подготовки данных и запуска приведены в `README.md`.
